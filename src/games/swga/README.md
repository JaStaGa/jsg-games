# SWGA

This module was migrated from the [JaStaGa/swga](https://github.com/JaStaGa/swga) repository at commit `f9e56e5594a163e5c9a4f163a8628fe07bca170d`.

This migration contains only the reusable game logic, board and keyboard derivation helpers, word data, and regression tests. Migrating a playable UI is the next separate step.

The approved 60-second mode has intentionally not been implemented yet.
